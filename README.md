# Student Performance Prediction Dashboard

## Project Objective

This project predicts student grades using Machine Learning and Streamlit.

## Dataset

Student Performance Dataset

## Features

- Home Page
- Dataset Information
- Manual Prediction
- CSV Upload
- Batch Prediction
- Download Prediction Results
- Model Performance
- About Project

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest

## Best Model

Random Forest Classifier

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
- Plotly

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
